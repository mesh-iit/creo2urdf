Reads the placement constraint-set type from the current feature's tree. Uses tree loaded by populateJointInfoFromElementTree(); this is the set type (for example PIN or FIXED), not an individual geometric constraint type.

Extracts a component feature's element tree and appends its joint information.

Parameters
[in]featComponent feature whose placement constraints define the joint.
[in,out]joint_info_mapJoint information indexed by the serialized component feature path; existing entries are preserved and duplicate keys are rejected.
[in]ownerIdPath from the exported root to the assembly owning feat, excluding feat's own ID. An empty path identifies the root assembly.
[in]compID_mdl_mapMap from root-relative occurrence paths to Creo model handles, including the root at the empty path, subassemblies, parts and excluded skeletons. Used to normalize and validate constraint reference paths.
Returns
True if a joint was inserted; false if the tree type is invalid, no usable reference pair exists, a skeleton is referenced or the joint type is unsupported.
Exceptions
std::runtime_errorIf references are invalid or ambiguous, multiple link pairs or constraint sets are found, or the joint occurrence already exists.

Converts a constraint selection into an occurrence path relative to the export root.

Parameters
[in]selectionAssembly-side or component-side constraint reference.
[in]fallbackExpected local occurrence when the selection has no rooted path: the owning assembly for an assembly reference, or the component for a component reference.
[in]componentIdFull path of the component feature being processed; its ancestry defines the allowed roots for the selection's relative path.
[in]compID_mdl_mapMap of occurrence paths to model handles, including the root, assemblies, parts and excluded skeletons, used to validate roots and leaf models.
[out]resultNormalized occurrence path; valid only when true is returned.
[out]failureDiagnostic reason when false is returned; unchanged on success.
Returns
True if the selection resolves unambiguously and matches its model owner; false for a missing selection, invalid path or inconsistent model reference.
Note
Does not modify class members. Model identity validates the path, while the full path distinguishes repeated occurrences of the same model.

Resolves the constraint selections to parent and child occurrences.

Parameters
[in]ownerIdRoot-relative path to the assembly owning wfeat, excluding the component feature's own ID; empty for the exported root assembly.
[in]compID_mdl_mapOccurrence-path-to-model map containing the root at the empty path and the collected assembly, part and skeleton handles. Reference roots are matched along the feature's ancestry and leaf models are validated.
Returns
True if m_parent_id and m_child_id identify a usable reference pair; false if no usable constraints exist or a reference belongs to a skeleton.
Exceptions
std::runtime_errorIf reference paths cannot be resolved, both endpoints identify the same occurrence or constraints identify different link pairs.
Note
Stores the constraints in the owning assembly occurrence's context for subsequent datum lookup. Parent and child IDs are valid only on success.
